# Soundcheck (فارسی)

> **کاوشگر قطعی وضعیت سلامت و تخصیص‌دهنده نقش‌ها برای ابزارهای هوش مصنوعی توسعه نرم‌افزار**

زبان‌ها: [English](../../README.md) · [Español](README.es.md) · [Français](README.fr.md)

ابزار **Soundcheck** وضعیت ابزارهای خط فرمان و ایجنت‌های کدنویسی نصب‌شده روی سیستم شما (`claude`، `codex`، `opencode`، `agy`، `gemini`، `copilot`) را پیش از واگذاری کارهای عملیاتی مورد آزمایش و ارزیابی دقیق قرار می‌دهد. این برنامه از اجرای دستورات با موفقیت کاذب (Exit Code 0 جعلی) جلوگیری می‌کند، خطاهای پنهان را استانداردسازی کرده و نقش‌های اجرایی (`primary`، `subagent`، `reviewer`، `auxiliary`) را به‌صورت قطعی و بدون مصرف توکن‌های گران‌قیمت مدل‌های زبانی تخصیص می‌دهد.

---

## ویژگی‌های اصلی

- **مهار خطاهای خروجی گمراه‌کننده (Fake Exit 0)**: بسیاری از ابزارهای CLI حتی هنگام اتمام سهمیه (Rate Limit) یا منقضی شدن توکن OAuth با کد خروج `0` پایان می‌یابند. Soundcheck خروجی‌ها را پایش کرده و آن‌ها را به کدهای واقعی (`429`، `401`، `corrupted`) تبدیل می‌کند.
- **تخصیص نقش با صفر توکن هزینه‌ای**: محاسبه و انتساب ایجنت‌ها برای نقش‌های اصلی و فرعی در کمتر از ۵۰ میکروثانیه با منطق قطعی، بدون ارسال پرامپت به مدل‌های هوش مصنوعی.
- **اجرای خودکار با انتقال بلادرنگ وظایف (Failover)**: اجرای پرامپت‌ها از طریق `soundcheck exec "prompt"`. در صورت بروز خطا در ایجنت اصلی، کار بدون توقف به ایجنت بعدی در زنجیره رزرو منتقل می‌شود.
- **کاوش و سنجش سلامت در ۴ لایه**:
  - **سطح L0 (حضور)**: بررسی وجود باینری و نسخه آن در مسیر سیستم `$PATH` (کمتر از ۱۵۰ میلی‌ثانیه).
  - **سطح L1 (احراز هویت)**: بررسی اعتبار ورود و نشست کاربر به همراه کش TTL جهت جلوگیری از ابطال توکن‌های نوسازی.
  - **سطح L2 (تست کارکرد سریع)**: اجرای ایمن، سریع و غیرمخرب جهت اطمینان از آمادگی ایجنت.
  - **سطح L3 (تست مدل زنده)**: اجرای استعلام کوتاه از مدل جهت تایید پاسخگویی واقعی.
- **باینری مستقل و یکپارچه**: کل سرور بک‌اند و رابط کاربری وب React درون یک فایل باینری مستقل فشرده شده است (حدود ۸.۳ مگابایت، کمتر از سقف مجاز ۲۰ مگابایت). بدون نیاز به نصب پیش‌نیازهایی مثل Node.js در زمان اجرا.
- **پروتکل ارتباطی مدل (MCP)**: پشتیبانی پیش‌فرض از سرور استاندارد Model Context Protocol برای اتصال مستقیم به نرم‌افزارهای Claude Desktop، Cursor و Antigravity.
- **افزونه رسمی VS Code**: در پوشه `editors/vscode` با نوار وضعیت بلادرنگ و داشبورد تعبیه‌شده در ادیتور.

## راهنمای نصب

### مک‌اواس و لینوکس
```bash
curl -fsSL https://raw.githubusercontent.com/soundcheck/soundcheck/main/scripts/install.sh | sh
```

### ویندوز (PowerShell)
```powershell
irm https://raw.githubusercontent.com/soundcheck/soundcheck/main/scripts/install.ps1 | iex
```

### هوم‌برو (Homebrew)
```bash
brew install soundcheck/tap/soundcheck
```

### اسکوپ (Scoop در ویندوز)
```powershell
scoop bucket add soundcheck https://github.com/soundcheck/scoop-bucket
scoop install soundcheck
```

### به‌روزرسانی خودکار
```bash
soundcheck upgrade
```

### بیلد از سورس کد
```bash
git clone https://github.com/soundcheck/soundcheck.git
cd soundcheck
make build
./bin/soundcheck doctor
```

## جدول دستورات خط فرمان (CLI)

| دستور | شرح عملکرد |
|---|---|
| `soundcheck doctor [--deep] [--json]` | اجرای عیب‌یابی جامع و نمایش جدول سلامت کلیه ایجنت‌ها |
| `soundcheck probe <adapter> [--deep]` | کاوش سلامت یک ابزار مشخص (مثال: `soundcheck probe claude`) |
| `soundcheck resolve [role]` | نمایش خروجی تخصیص قطعی نقش‌ها بر اساس سیاست‌های پروژه |
| `soundcheck exec <prompt> [--role <role>]` | اجرای پرامپت در پس‌زمینه با قابلیت جایگزینی خودکار در صورت خطا |
| `soundcheck run <adapter> [-- <args>]` | آغاز نشست تعاملی ترمینال خام PTY با ارسال مستقیم خروجی |
| `soundcheck manifest [--json]` | صدور مانیفست کامل قابلیت‌ها و وضعیت سلامت به فرمت JSON |
| `soundcheck serve [--port 3000] [--token <token>]` | راه‌اندازی سرور HTTP و وب‌اپلیکیشن روی پورت مشخص (پیش‌فرض: ۳۰۰۰) |
| `soundcheck mcp` | راه‌اندازی سرور استانداردی Model Context Protocol بر بستر stdio |
| `soundcheck upgrade [--check]` | بررسی نسخه‌های جدید منتشرشده و جایگزینی باینری فعلی |
| `soundcheck version` | نمایش شماره نسخه و اطلاعات بیلد باینری |

## فهرست مسیرهای وب‌سرویس (REST API)

با اجرای `soundcheck serve [--port 3000]` اندپوینت‌های زیر فعال می‌گردند:

| اندپوینت | متد | شرح وظیفه |
|---|---|---|
| `/api/health` | `GET` | بررسی زنده بودن سرور و نمایش نسخه |
| `/api/v1/doctor` | `GET` | دریافت گزارش کاوش سلامت (پشتیبانی از SSE با هدر `Accept: text/event-stream`) |
| `/api/v1/probe` | `GET` | اجرای کاوش همگانی در تمامی ابزارهای CLI |
| `/api/v1/probe/{id}` | `POST` | اجرای کاوش مجزا برای یک ایجنت انتخابی |
| `/api/v1/resolve` | `GET`, `POST` | حل قطعی نقش‌ها و نمایش دلایل زنجیره انتخاب |
| `/api/v1/manifest` | `GET` | صدور ساختار کامل قابلیت‌ها در فرمت استاندارد JSON |
| `/api/v1/config` | `GET` | خواندن تنظیمات جاری پروژه (به همراه هدر `X-Config-Path`) |
| `/api/v1/config` | `PUT` | ذخیره اتمیک و معتبرسازی‌شده فایل پیکربندی در فایل YAML |
| `/api/v1/config/validate` | `POST` | ارزیابی گزینه‌های انتخابی نقش‌ها در برابر ابزارهای واقعی نصب‌شده |
| `/api/v1/terminal/ws` | `WS` | سوکت دوطرفه برای ترمینال PTY در داشبورد وب |

## کشف خودکار مدل‌های اکانت (`modelsCommand`)

هر ابزار می‌تواند به شکل اختیاری دارای دستور کشف مدل‌ها باشد (مانند `modelsCommand: "codex debug models"` برای Codex):

- **در صورت وجود دستور**: با اجرای آزمون، مدل‌های فعال روی حساب کاربری واقعی دریافت شده و جایگزین داده‌های فرضی می‌شوند. قیمت مدل‌های شناخته‌شده مطابق مستندات رسمی تنظیم شده و مدل‌های جدید با هزینه نامشخص علامت‌گذاری می‌شوند تا ارقام غیرواقعی تولید نگردد.
- **در صورت عدم وجود دستور**: ابزار از فهرست مطمئن و اعتبارسنجی‌شده مندرج در فایل تنظیمات YAML استفاده خواهد کرد.

## معماری سامانه

برنامه Soundcheck بر پایه اصول سخت‌گیرانه **معماری شش‌ضلعی (Hexagonal Architecture)** پیاده‌سازی شده است:

- **هسته تابعی خالص (Pure Functional Core)** در مسیر `internal/core/*`:
  - صددرصد قطعی: داده ورودی → داده خروجی.
  - بدون انجام هرگونه ورودی/خروجی، بدون وابستگی به زمان مستقیم سیستم، بدون دسترسی به متغیرهای محیطی یا همزمانی.
  - استفاده انحصاری از کتابخانه استاندارد Go که خلوص آن با تست معماری `internal/arch_test.go` تضمین می‌شود.
- **پوسته اجرایی (Imperative Shell)** در مسیرهای `internal/edge/*` و `internal/transport/*`:
  - مدیریت پردازش‌ها، کنترل نشست‌های PTY، ذخیره فایل‌ها و فراخوانی شبکه.
  - لایه‌های ارتباطی: ترمینال خط فرمان، سرور وب و واسط MCP.
